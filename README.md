# Instituto Futuro Verde
Projeto prático de desenvolvimento frontend desenvolvido como exercício acadêmico (Unicsul).

## Tecnologias
- HTML5 (estruturação semântica)
- CSS3 (estilização e layout)

## Estrutura
- `index.html`: Página principal
- `cadastro.html`: Página de cadastro
- `projetos.html`: Página de apresentação de iniciativas
- `css/style.css`: Folha de estilos
